# 03: Compact Card Decision Hierarchy

**What to build:** Make each setup card useful for fast review by promoting authoritative decision essentials and keeping richer context in the drawer with explicit availability states.

**Blocked by:** 01 — Freshness and Decision-Lane Separation

**Status:** ready-for-agent

## Acceptance criteria

- [ ] Card prominently shows price/% change, lane/action, Wave/confidence, and freshness/data status.
- [ ] Card shows authoritative Trigger, Stop, Target 1, and R/R when available.
- [ ] RS renders to two digits.
- [ ] 52W/ATH/breakout evidence uses plain, compact, non-ambiguous labels.
- [ ] Sector/Industry, Peer context, VCP bonus, full evidence, and provenance remain available in the drawer.
- [ ] Missing values render explicit `Not available`/equivalent status with provenance rather than unexplained dashes.
- [ ] List/drawer values remain consistent for a representative symbol.
- [ ] Desktop and 390px mobile screenshots show readable hierarchy, color semantics, and no horizontal overflow.
