# Signalix Postmortems

Store major incident postmortems here only when the lesson is durable and reusable.
Do not dump routine debug logs; Level 2 session history already stores raw conversations.

Suggested format:

```md
# YYYY-MM-DD — Incident title

## Symptom

## Root Cause

## Fix

## Verification

## Prevention / Skill or Memory Update
```
